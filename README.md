# 🎮 Meu Jogo

Bem-vindo ao repositório do meu jogo! Este é um projeto em desenvolvimento para criar um jogo web interativo.

## 📁 Estrutura do Projeto

```
meusite/
├── index.html          # Arquivo principal HTML
├── css/
│   └── style.css       # Estilos do jogo
├── js/
│   └── game.js         # Lógica do jogo
└── README.md           # Este arquivo
```

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/edineisouzasatos-hue/meusite.git
```

2. Abra o arquivo `index.html` no seu navegador:
```bash
cd meusite
open index.html
```

Ou use um servidor local:
```bash
python -m http.server 8000
# ou
npx http-server
```

3. Jogue! Use as **setas** ou **WASD** para se mover.
